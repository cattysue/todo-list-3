# Story 6.1: 주간·월간 완료율 통계 차트

Status: done

## Story

사용자(Catty)로서,
통계 페이지에서 주간·월간 완료 개수와 완료율을 차트로 보는 것을 원한다,
내 생산성이 시간에 따라 어떻게 변화하는지 데이터로 파악할 수 있도록.

## Acceptance Criteria

1. **통계 페이지 진입**: `/stats` 페이지에 접근하면 주간 뷰와 월간 뷰 전환 탭이 표시된다. 선택된 기간의 완료 개수와 완료율이 차트로 표시된다.

2. **주간 뷰 차트**: 주간 뷰 선택 시 최근 8주간 각 주의 완료 개수(막대)와 완료율(%)이 Recharts 차트로 표시된다.

3. **월간 뷰 차트**: 월간 뷰 선택 시 최근 6개월간 각 월의 완료 개수(막대)와 완료율(%)이 Recharts 차트로 표시된다.

4. **통계 API**: `GET /stats/completion?period=weekly&count=8` 또는 `?period=monthly&count=6` 호출 시 `completed_at` 기준으로 기간별 집계된 데이터가 반환된다. 마감일 없이 완료된 할일도 집계에 포함된다.

5. **`completed_at` 컬럼**: 할일 완료 처리(`PATCH /todos/{id}`) 시 `completed_at = NOW()` 가 DB에 자동 기록된다. 기존 완료 할일은 `NULL`이며, 신규 완료 분부터 집계된다.

- [x] Task 4: `backend/services/stats.py` 신규 생성 (AC: 4)
  ```python
  from datetime import datetime, timezone, timedelta
  from typing import Literal

  def get_completion_stats(
      user_id: str,
      supabase,
      period: Literal["weekly", "monthly"],
      count: int,
  ) -> dict:
      """
      completed_at 기준으로 기간별 완료 통계를 집계한다.
      completed_count: 해당 기간에 completed_at이 속하는 완료된 할일 수
      total_count: 해당 기간에 created_at이 속하는 모든 할일 수
      completion_rate: completed_count / total_count * 100 (total=0이면 0.0)
      """
      now = datetime.now(timezone.utc)
      periods = _build_periods(now, period, count)

      # 관련 기간 전체 범위로 한 번만 조회
      earliest_start = periods[0]["start"]

      # 완료된 할일: completed_at이 범위 내
      completed_rows = (
          supabase.table("todos")
          .select("id, completed_at, created_at")
          .eq("user_id", user_id)
          .eq("is_completed", True)
          .gte("completed_at", earliest_start.isoformat())
          .lte("completed_at", now.isoformat())
          .execute()
          .data
      ) or []

      # 모든 할일: created_at이 범위 내
      all_rows = (
          supabase.table("todos")
          .select("id, created_at")
          .eq("user_id", user_id)
          .gte("created_at", earliest_start.isoformat())
          .lte("created_at", now.isoformat())
          .execute()
          .data
      ) or []

      result = []
      for p in periods:
          completed_count = sum(
              1 for r in completed_rows
              if r.get("completed_at") and p["start"] <= _parse_dt(r["completed_at"]) < p["end"]
          )
          total_count = sum(
              1 for r in all_rows
              if r.get("created_at") and p["start"] <= _parse_dt(r["created_at"]) < p["end"]
          )
          rate = round(completed_count / total_count * 100, 1) if total_count > 0 else 0.0
          result.append({
              "label": p["label"],
              "completed_count": completed_count,
              "total_count": total_count,
              "completion_rate": rate,
          })

      return {"period": period, "data": result}


  def _parse_dt(dt_str: str) -> datetime:
      """ISO 문자열 → timezone-aware datetime."""
      dt = datetime.fromisoformat(dt_str.replace("Z", "+00:00"))
      if dt.tzinfo is None:
          dt = dt.replace(tzinfo=timezone.utc)
      return dt


  def _build_periods(now: datetime, period: str, count: int) -> list[dict]:
      """
      가장 오래된 기간부터 최근 기간 순으로 count개 기간 목록을 반환한다.
      """
      periods = []
      if period == "weekly":
          # ISO 주 기준: 월요일 시작
          current_monday = now - timedelta(days=now.weekday())
          current_monday = current_monday.replace(hour=0, minute=0, second=0, microsecond=0)
          for i in range(count - 1, -1, -1):
              week_start = current_monday - timedelta(weeks=i)
              week_end = week_start + timedelta(weeks=1)
              iso_year, iso_week, _ = week_start.isocalendar()
              periods.append({
                  "label": f"{iso_year}-W{iso_week:02d}",
                  "start": week_start,
                  "end": week_end,
              })
      else:  # monthly
          current_month_start = now.replace(day=1, hour=0, minute=0, second=0, microsecond=0)
          for i in range(count - 1, -1, -1):
              # count-1달 전부터 이번 달까지
              year = current_month_start.year
              month = current_month_start.month - i
              while month <= 0:
                  month += 12
                  year -= 1
              month_start = current_month_start.replace(year=year, month=month, day=1)
              if month == 12:
                  month_end = month_start.replace(year=year + 1, month=1, day=1)
              else:
                  month_end = month_start.replace(month=month + 1, day=1)
              periods.append({
                  "label": f"{year}-{month:02d}",
                  "start": month_start,
                  "end": month_end,
              })
      return periods
  ```

  import type { CompletionStatsResponse, StatsPeriod } from '@/types/stats';

  export async function getCompletionStats(
    period: StatsPeriod,
    count: number,
  ): Promise<CompletionStatsResponse> {
    const token = await getAccessToken();
    const params = new URLSearchParams({ period, count: String(count) });
    const res = await fetch(
      `${process.env.NEXT_PUBLIC_API_URL}/stats/completion?${params.toString()}`,
      { headers: { Authorization: `Bearer ${token}` } },
    );
    if (!res.ok) throw new Error(`통계 조회 오류: ${res.status}`);
    return res.json() as Promise<CompletionStatsResponse>;
  }

## Dev Notes

### ⚠️ 핵심 사전 작업: `completed_at` 컬럼 미존재

현재 `todos` 테이블에 `completed_at` 컬럼이 없다. `services/todos.py`의 `complete_todo`는 `is_completed: True`만 설정한다. 이 스토리의 모든 통계 기능이 `completed_at`에 의존하므로 **Task 1~2가 가장 먼저** 실행되어야 한다.

⚠️ **DB 마이그레이션은 개발자(Catty)가 Supabase 대시보드에서 직접 실행해야 한다**. SQL 파일을 생성하는 것과 실행하는 것을 혼동하지 말 것.

기존 완료된 할일(`is_completed = True`)은 `completed_at = NULL`이 되므로 통계에서 집계되지 않는다. 이는 의도된 동작이며, 신규 완료 건부터 통계가 쌓인다.

### 통계 집계 로직 상세

**period="weekly"의 경우 (count=8):**
- 현재 주의 월요일 00:00 UTC부터 시작
- 8주 전 월요일부터 현재 주 끝까지
- 라벨: ISO 주 형식 `YYYY-WNN` (예: "2026-W22")

**period="monthly"의 경우 (count=6):**
- 현재 월 1일부터 시작
- 5개월 전 1일부터 현재 월 끝까지
- 라벨: `YYYY-MM` (예: "2026-06")

**completed_count vs total_count:**
- `completed_count`: `completed_at`이 해당 기간에 속하는 완료된 할일 수
- `total_count`: `created_at`이 해당 기간에 속하는 모든 할일 수 (완료/미완료 무관)
- `completion_rate`: `completed_count / total_count * 100` (total=0이면 0.0)
- 마감일 없는 할일도 포함 (`due_date` 필터 없음)

### `services/todos.py` 수정 범위

`complete_todo` 함수에서 update 딕셔너리만 변경:
```python
# 변경 전
.update({"is_completed": True})

# 변경 후
.update({
    "is_completed": True,
    "completed_at": datetime.now(timezone.utc).isoformat(),
})
```

기존 테스트에서 `complete_todo` mock이 `is_completed: True`만 확인하므로 **기존 테스트 영향 없음**. 단, `_COMPLETE_SELECT`에 `completed_at` 추가 시 mock 데이터 반환에 `completed_at` 없어도 정상 동작함 (`_normalize_row`에서 무시됨).
