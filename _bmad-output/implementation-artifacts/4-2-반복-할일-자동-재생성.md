# Story 4.2: 반복 할일 자동 재생성

Status: review

## Story

사용자(Catty)로서,
반복 주기가 설정된 할일을 완료하면 다음 주기의 인스턴스가 자동으로 생성되는 것을 원한다,
매일 직접 입력하지 않아도 루틴 할일이 대시보드에 자동으로 나타나도록.

## Acceptance Criteria

1. **반복 할일 완료 시 자동 재생성**: 반복 주기가 설정된 할일을 완료 처리할 때, 지정된 주기의 다음 마감일로 새 할일 인스턴스가 자동 생성된다. 새 인스턴스는 원본 할일과 동일한 제목·카테고리·우선순위·반복 설정을 가진다.

2. **매일 반복 — 다음 마감일 계산**: 매일 반복 할일을 완료할 때, 새 인스턴스의 마감일이 오늘로부터 +1일로 설정된다.

3. **매주 반복 — 다음 마감일 계산**: 매주 반복 할일을 완료할 때, 새 인스턴스의 마감일이 지정된 요일 기준 오늘 이후 첫 번째 발생일로 설정된다. 복수 요일(예: 월/수/금)인 경우 오늘 이후 가장 가까운 지정 요일로 설정된다.

4. **매월 반복 — 다음 마감일 계산**: 매월 반복 할일을 완료할 때, 새 인스턴스의 마감일이 다음 달 지정 날짜로 설정된다. 다음 달에 해당 날짜가 없으면(예: 31일 → 2월) 해당 달의 마지막 날로 설정된다.

5. **일반 할일 영향 없음**: 반복 주기가 없는 일반 할일을 완료할 때, 새 인스턴스가 생성되지 않고 기존 완료 처리 동작이 유지된다.

6. **완료 처리 실패 방지**: 다음 인스턴스 생성 도중 오류가 발생해도 원본 할일의 완료 처리가 취소되지 않는다. 완료는 항상 성공으로 반환한다.

### `calculate_next_due_date` 전체 구현 패턴

```python
# backend/services/recurring.py
import calendar
from datetime import date, timedelta
from typing import Optional


def calculate_next_due_date(
    recurrence_type: str,
    recurrence_days: Optional[str] = None,
    recurrence_day_of_month: Optional[int] = None,
) -> str:
    today = date.today()

    if recurrence_type == "daily":
        return (today + timedelta(days=1)).isoformat()

    if recurrence_type == "weekly":
        if not recurrence_days:
            return (today + timedelta(days=7)).isoformat()
        days = {int(d) for d in recurrence_days.split(",")}
        today_wd = today.weekday()  # Python: 0=월, 6=일 (recurrence_days 규칙과 동일)
        for delta in range(1, 8):
            if (today_wd + delta) % 7 in days:
                return (today + timedelta(days=delta)).isoformat()
        return (today + timedelta(days=7)).isoformat()  # fallback (shouldn't reach)

    if recurrence_type == "monthly":
        day = recurrence_day_of_month or 1
        if today.month == 12:
            y, m = today.year + 1, 1
        else:
            y, m = today.year, today.month + 1
        max_day = calendar.monthrange(y, m)[1]
        return date(y, m, min(day, max_day)).isoformat()

    raise ValueError(f"알 수 없는 반복 유형: {recurrence_type}")
```

**요일 인덱스 규칙**: Python `date.weekday()` → 0=월, 6=일. Story 4.1에서 정의한 `recurrence_days` 규칙(0=월, 6=일)과 동일 — 별도 변환 불필요.

### `_mock_update_with_select` 헬퍼 추가

기존 `_mock_update`는 `.select()` 없는 체인에 사용되고, `complete_todo`는 `.update().eq().eq().select().execute()` 체인을 사용하므로 새 헬퍼 필요:

```python
def _mock_update_with_select(returned_rows: list[dict]) -> MagicMock:
    """update → eq → eq → select → execute 체인 mock (recurrence 필드 포함)."""
    mock = MagicMock()
    for method in ["table", "update", "select", "eq", "single", "insert"]:
        getattr(mock, method).return_value = mock
    execute_result = MagicMock()
    execute_result.data = returned_rows
    mock.execute.return_value = execute_result
    return mock
```
