# Story 4.3: 반복 유연 제어

Status: review

## Story

사용자(Catty)로서,
반복 할일에 "이번만 건너뛰기 / 일시 중지 / 반복 종료" 옵션을 적용하는 것을 원한다,
예외적인 상황에서도 반복 패턴을 유연하게 조절할 수 있도록.

## Acceptance Criteria

1. **옵션 메뉴 표시**: 반복 주기가 설정된 할일이 표시되어 있을 때, 해당 할일의 옵션 메뉴를 열면 "이번만 건너뛰기", "일시 중지", "반복 종료" 옵션이 표시된다.

2. **이번만 건너뛰기**: "이번만 건너뛰기"를 선택할 때, 현재 인스턴스가 완료 처리 없이 삭제되고 다음 주기 인스턴스가 생성된다. 반복 설정 자체는 신규 인스턴스에 유지된다.

3. **일시 중지**: "일시 중지"를 선택할 때, 현재 인스턴스 이후 새 인스턴스가 생성되지 않는다 (완료해도 다음 인스턴스 미생성). 재개 옵션이 표시되어 언제든 반복을 다시 활성화할 수 있다.

4. **재개**: 일시 중지된 반복 할일에서 재개를 선택할 때, 다음 주기 마감일로 새 인스턴스가 생성된다. 현재 인스턴스의 일시 중지 상태가 해제된다.

5. **반복 종료**: "반복 종료"를 선택할 때, 현재 인스턴스 이후 더 이상 새 인스턴스가 생성되지 않는다. 반복 설정(recurrence_type/days/day_of_month)이 제거되어 현재 인스턴스가 일반 할일로 전환된다.

6. **비반복 할일 영향 없음**: 반복 주기가 없는 일반 할일에는 옵션 메뉴가 표시되지 않는다.

    ```python
    def control_recurrence(todo_id: str, user_id: str, action: str, supabase) -> Optional[dict]:
        """반복 할일 제어: skip / pause / resume / end."""
        todo = get_todo(todo_id=todo_id, user_id=user_id, supabase=supabase)
        if not todo or not todo.get("recurrence_type"):
            return None

        if action == "skip":
            next_due = calculate_next_due_date(
                recurrence_type=todo["recurrence_type"],
                recurrence_days=todo.get("recurrence_days"),
                recurrence_day_of_month=todo.get("recurrence_day_of_month"),
            )
            create_todo(
                user_id=user_id,
                supabase=supabase,
                title=todo["title"],
                category_id=todo.get("category_id"),
                priority=todo.get("priority"),
                due_date=next_due,
                recurrence_type=todo["recurrence_type"],
                recurrence_days=todo.get("recurrence_days"),
                recurrence_day_of_month=todo.get("recurrence_day_of_month"),
            )
            supabase.table("todos").delete().eq("id", todo_id).eq("user_id", user_id).execute()
            return {"id": todo_id, "action": action}

        if action == "pause":
            update_todo_content(
                todo_id=todo_id, user_id=user_id, supabase=supabase,
                updates={"recurrence_paused": True},
            )
            return {"id": todo_id, "action": action}

        if action == "resume":
            update_todo_content(
                todo_id=todo_id, user_id=user_id, supabase=supabase,
                updates={"recurrence_paused": False},
            )
            next_due = calculate_next_due_date(
                recurrence_type=todo["recurrence_type"],
                recurrence_days=todo.get("recurrence_days"),
                recurrence_day_of_month=todo.get("recurrence_day_of_month"),
            )
            create_todo(
                user_id=user_id,
                supabase=supabase,
                title=todo["title"],
                category_id=todo.get("category_id"),
                priority=todo.get("priority"),
                due_date=next_due,
                recurrence_type=todo["recurrence_type"],
                recurrence_days=todo.get("recurrence_days"),
                recurrence_day_of_month=todo.get("recurrence_day_of_month"),
            )
            return {"id": todo_id, "action": action}

        if action == "end":
            update_todo_content(
                todo_id=todo_id, user_id=user_id, supabase=supabase,
                updates={
                    "recurrence_type": None,
                    "recurrence_days": None,
                    "recurrence_day_of_month": None,
                    "recurrence_paused": False,
                },
            )
            return {"id": todo_id, "action": action}

        return None
    ```

    ```typescript
        `${process.env.NEXT_PUBLIC_API_URL}/todos/${todoId}/recurrence`,
        {

            'Content-Type': 'application/json',

          body: JSON.stringify({ action }),
        },
    ```

### 핵심 설계 결정

**recurrence_paused 컬럼 추가 이유:**
- `pause` 상태를 별도 테이블 없이 `todos` 컬럼으로 관리 — 단순성 유지
- `complete_todo`에서 `recurrence_paused = True`이면 다음 인스턴스 생성 건너뜀
- `end` 액션: `recurrence_type = NULL` → 일반 할일 전환 (기존 스키마 활용)

**`skip` 구현 방식 (삭제 + 신규 생성):**
- "이번만 건너뛰기" = 현재 인스턴스 제거 + 다음 주기 인스턴스 생성
- `create_todo` 먼저 → 성공 후 `delete` — 생성 실패 시 삭제 안 함 (데이터 유실 방지)
- 삭제에는 Supabase `.delete().eq("id", ...).eq("user_id", ...)` 직접 사용 (서비스 레이어 내부에서만)

**`resume` 구현 방식:**
- 현재 인스턴스: `recurrence_paused = False`로 복원
- 다음 인스턴스: `calculate_next_due_date`로 다음 주기 날짜 계산 → `create_todo`

**옵션 메뉴 상태 관리:**
- `openMenuId` state: `DashboardSection` 내부 로컬 상태 (외부로 노출 불필요)
