# Story 3.1: 키워드 실시간 검색

Status: review

## Story

사용자(Catty)로서,
검색창에 키워드를 입력하면 전체 할일 제목에서 실시간으로 결과를 확인하는 것을 원한다,
수많은 할일 중 특정 할일을 빠르게 찾을 수 있도록.

## Acceptance Criteria

1. **debounce 300ms**: 검색창에 키워드를 입력할 때 마지막 입력으로부터 300ms가 경과해야 API 호출이 발생한다. 300ms 이내 연속 입력 시 API 호출이 발생하지 않는다.

2. **빈 검색어 → 전체 목록**: 검색창에 키워드가 없을 때 전체 할일 목록이 표시된다.

3. **결과 없음 상태**: 검색 키워드가 어떤 할일 제목과도 일치하지 않을 때 "검색 결과 없음" 빈 상태 메시지가 표시된다.

4. **결과 항목 표시 필드**: 검색 결과 각 항목에 할일 제목, 마감일, 우선순위, 카테고리 이름이 함께 표시된다.

### debounce 구현 패턴

```typescript
// frontend/src/hooks/useDebounce.ts
import { useState, useEffect } from 'react';

export function useDebounce<T>(value: T, delay: number): T {
  const [debouncedValue, setDebouncedValue] = useState<T>(value);

  useEffect(() => {
    const timer = setTimeout(() => {
      setDebouncedValue(value);
    }, delay);
    return () => clearTimeout(timer);
  }, [value, delay]);

  return debouncedValue;
}
```

### useSearchTodos 구현 패턴

```typescript
// frontend/src/hooks/useSearchTodos.ts
import { useQuery } from '@tanstack/react-query';
import { searchTodos } from '@/lib/api';
import { queryKeys } from '@/lib/queryKeys';
import { useDebounce } from '@/hooks/useDebounce';

export function useSearchTodos(query: string) {
  const debouncedQuery = useDebounce(query, 300);

  const result = useQuery({
    queryKey: queryKeys.todos.search(debouncedQuery),
    queryFn: () => searchTodos(debouncedQuery),
  });

  return { ...result, debouncedQuery };
}
```

### searchTodos API 함수 패턴

```typescript
// frontend/src/lib/api.ts — completeTodo 아래에 추가
export async function searchTodos(q: string): Promise<TodoDashboardItem[]> {
  const token = await getAccessToken();
  const url = q
    ? `${process.env.NEXT_PUBLIC_API_URL}/todos/search?q=${encodeURIComponent(q)}`
    : `${process.env.NEXT_PUBLIC_API_URL}/todos/search`;
  const res = await fetch(url, {
    headers: {
      Authorization: `Bearer ${token}`,
      'Content-Type': 'application/json',
    },
  });
  if (!res.ok) throw new Error(`검색 오류: ${res.status}`);
  return res.json() as Promise<TodoDashboardItem[]>;
}
```

### 백엔드 검색 서비스 패턴

```python
# backend/services/search.py (신규)
from typing import Any, Optional

from schemas.dashboard import TodoDashboardItem
from services.dashboard import _build_item  # 기존 헬퍼 재사용


def search_todos(
    user_id: str,
    supabase,
    q: Optional[str] = None,
) -> list[TodoDashboardItem]:
    query = (
        supabase.table("todos")
        .select("*, categories(name)")
        .eq("user_id", user_id)
    )

    if q:
        query = query.ilike("title", f"%{q}%")

    response = query.order("created_at", desc=True).execute()
    rows: list[dict[str, Any]] = response.data or []
    return [_build_item(row) for row in rows]
```

### TanStack Query 캐시 무효화 — 기존 코드 수정 불필요

`useCompleteTodo.ts`의 `onSuccess`에서 `invalidateQueries({ queryKey: queryKeys.todos.all })` 호출 시:
- `todos.all = ['todos']` — TanStack Query는 이 prefix로 시작하는 모든 쿼리를 무효화
- `['todos', 'search', '']` ✅ 자동 무효화
- `['todos', 'search', '프로젝트']` ✅ 자동 무효화
- `['todos', 'dashboard']` ✅ 자동 무효화 (기존 동작 유지)

→ **`useCompleteTodo.ts` 수정 불필요**
