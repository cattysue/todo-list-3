# Story 5.2: 드래그로 마감일 변경

Status: done

## Story

사용자(Catty)로서,
캘린더 뷰에서 할일을 다른 날짜로 드래그하여 마감일을 변경하는 것을 원한다,
날짜 수정 폼을 열지 않고도 일정을 직관적으로 재조정할 수 있도록.

## Acceptance Criteria

1. **드래그로 마감일 변경**: 캘린더의 할일 항목을 다른 날짜 셀로 드래그하여 놓으면 해당 할일의 마감일이 드롭된 날짜로 즉시 변경된다. 캘린더에서 할일이 새 날짜 셀로 즉시 이동된다.

2. **대시보드/카테고리 뷰 반영**: 드래그 성공 시 서버에 변경사항이 저장되고, `queryKeys.todos.all` 캐시 무효화로 대시보드 및 카테고리 뷰에도 반영된다.

3. **롤백(에러 처리)**: 서버 저장 실패 시 할일이 원래 날짜로 롤백되어 캘린더에 다시 표시된다. 한국어 에러 메시지가 표시된다.

4. **드래그 중 시각적 강조**: 드래그 중에 드롭 가능한 날짜 셀이 파란색으로 강조되어 정확한 날짜에 놓을 수 있다.

  ```typescript
  export async function updateTodoDueDate(todoId: string, dueDate: string): Promise<void> {
    const token = await getAccessToken();
    const res = await fetch(`${process.env.NEXT_PUBLIC_API_URL}/todos/${todoId}`, {
  ```

- [x] Task 3: `frontend/src/hooks/useDragDueDate.ts` 신규 생성 (AC: 1, 2, 3)
  ```typescript
  import { useMutation, useQueryClient } from '@tanstack/react-query';
  import { updateTodoDueDate } from '@/lib/api';
  import { queryKeys } from '@/lib/queryKeys';
  import type { TodoCalendarItem } from '@/types/calendar';

  interface DragDueDateVars {
    todoId: string;
    newDueDate: string;      // YYYY-MM-DD
    previousDueDate: string; // YYYY-MM-DD (롤백용)
    calendarStart: string;   // 현재 뷰 range.start (캐시 키 조회용)
    calendarEnd: string;     // 현재 뷰 range.end
  }

  export function useDragDueDate() {
    const queryClient = useQueryClient();

    return useMutation({
      mutationFn: ({ todoId, newDueDate }: DragDueDateVars) =>
        updateTodoDueDate(todoId, newDueDate),

      onMutate: async ({ todoId, newDueDate, calendarStart, calendarEnd }) => {
        const calendarKey = queryKeys.todos.calendar(calendarStart, calendarEnd);
        await queryClient.cancelQueries({ queryKey: calendarKey });

        const previousData = queryClient.getQueryData<TodoCalendarItem[]>(calendarKey);

        queryClient.setQueryData<TodoCalendarItem[]>(calendarKey, (old) => {
          if (!old) return old;
          return old.map((todo) =>
            todo.id === todoId ? { ...todo, due_date: newDueDate } : todo,
          );
        });

        return { previousData, calendarKey };
      },

      onError: (_err, _vars, context) => {
        if (context?.previousData !== undefined) {
          queryClient.setQueryData(context.calendarKey, context.previousData);
        } else if (context?.calendarKey) {
          queryClient.invalidateQueries({ queryKey: context.calendarKey });
        }
        alert('마감일 변경 중 오류가 발생했습니다. 다시 시도해 주세요.');
      },

      onSuccess: () => {
        queryClient.invalidateQueries({ queryKey: queryKeys.todos.all });
      },
    });
  }
  ```

- [x] Task 4: `frontend/src/components/calendar/DraggableTodoItem.tsx` 신규 생성 (AC: 1, 4)

  ```tsx
  import { useDraggable } from '@dnd-kit/core';
  import { CSS } from '@dnd-kit/utilities';
  import type { TodoCalendarItem } from '@/types/calendar';

  interface Props {
    todo: TodoCalendarItem;
  }

  export function DraggableTodoItem({ todo }: Props) {
    const { attributes, listeners, setNodeRef, transform, isDragging } = useDraggable({
      id: todo.id,
    });

    const style: React.CSSProperties | undefined = transform
      ? {
          transform: CSS.Translate.toString(transform),
          opacity: isDragging ? 0.5 : 1,
          zIndex: isDragging ? 50 : undefined,
        }
      : undefined;

    return (
      <li
        ref={setNodeRef}
        style={style}
        {...listeners}
        {...attributes}
        className={[
          'truncate text-xs px-1 rounded cursor-grab active:cursor-grabbing',
          todo.is_completed
            ? 'line-through text-gray-400 bg-gray-100'
            : 'bg-blue-100 text-blue-800',
        ].join(' ')}
      >
        {todo.title}
      </li>
    );
  }
  ```

  ```tsx
  import { useDroppable } from '@dnd-kit/core';
  import { formatDate } from '@/lib/calendarUtils';
  import { DraggableTodoItem } from './DraggableTodoItem';
  import type { TodoCalendarItem } from '@/types/calendar';

  const MAX_VISIBLE = 3;

  interface Props {
    date: Date;
    todos: TodoCalendarItem[];
    isCurrentMonth: boolean;
    isToday: boolean;
    isSelected: boolean;
    onClick: (dateStr: string) => void;

  export function DayCell({ date, todos, isCurrentMonth, isToday, isSelected, onClick }: Props) {
    const dateStr = formatDate(date);
    const { setNodeRef, isOver } = useDroppable({ id: dateStr });

    const visible = todos.slice(0, MAX_VISIBLE);
    const overflow = todos.length - MAX_VISIBLE;

    return (
      <div
        ref={setNodeRef}
        onClick={() => onClick(dateStr)}
        className={[
          'min-h-20 p-1 cursor-pointer border rounded text-sm transition-colors',
          isCurrentMonth ? 'bg-white' : 'bg-gray-50 text-gray-400',
          isToday ? 'border-blue-500' : 'border-gray-200',
          isSelected ? 'ring-2 ring-blue-400' : '',
          isOver ? 'bg-blue-50 border-blue-400' : '',

      >
        <span className={['font-semibold text-xs', isToday ? 'text-blue-600' : ''].join(' ')}>
          {date.getDate()}
        </span>
        <ul className="mt-1 space-y-0.5">
          {visible.map((todo) => (
            <DraggableTodoItem key={todo.id} todo={todo} />
          ))}
          {overflow > 0 && (
            <li className="text-xs text-gray-500">+{overflow}개 더</li>
          )}
        </ul>
      </div>
    );
  }
  ```

### @dnd-kit/core 주요 API

```typescript
// DndContext — 드래그 영역 경계 지정
import { DndContext, DragEndEvent } from '@dnd-kit/core';
<DndContext onDragEnd={handleDragEnd}>...</DndContext>

// useDraggable — 드래그 가능한 항목
const { attributes, listeners, setNodeRef, transform, isDragging } = useDraggable({ id: 'unique-id' });

// useDroppable — 드롭 대상 영역
const { setNodeRef, isOver } = useDroppable({ id: 'date-string' });

// CSS.Translate.toString — transform 값을 CSS 문자열로 변환
import { CSS } from '@dnd-kit/utilities';
const style = { transform: CSS.Translate.toString(transform) };
```

**드래그 동작 메커니즘:**
- `active.id` = 드래그 중인 요소의 id (todo.id)
- `over.id` = 드롭된 드롭 존의 id (날짜 문자열 YYYY-MM-DD)
- `over === null` = 드롭 존 밖에서 놓음 → 무시

**onClick 충돌 방지:**
dnd-kit은 드래그 동작(포인터 이동 감지 후)과 클릭 이벤트를 자동 구분한다. 짧은 탭은 클릭으로 처리, 이동 후 드롭은 드래그로 처리. 별도 처리 불필요.

### 캐시 업데이트 전략

`useDragDueDate.onMutate`에서:
```typescript
const previousData = queryClient.getQueryData<TodoCalendarItem[]>(calendarKey);

queryClient.setQueryData<TodoCalendarItem[]>(calendarKey, (old) => {
  if (!old) return old;
  return old.map((todo) =>
    todo.id === todoId ? { ...todo, due_date: newDueDate } : todo,
  );
});
```

`todosByDate` useMemo는 `todos` 배열에서 파생되므로, 캐시의 `due_date`가 바뀌면 자동으로 재계산되어 할일이 새 날짜 셀로 이동된다.

에러 시 `context.previousData`로 롤백:
```typescript
queryClient.setQueryData(context.calendarKey, context.previousData);
```

### DayCell에서 드래그/클릭 분리 주의사항

`DayCell` 자체에 `onClick`이 있고, 내부 `DraggableTodoItem`에 `listeners` (포인터 이벤트)가 있다. 이벤트 버블링 때문에 할일을 클릭하면 `DayCell.onClick`도 발생할 수 있다.

**해결책**: `DraggableTodoItem`의 클릭 이벤트에서 `e.stopPropagation()` 추가:
```tsx
<li
  ref={setNodeRef}
  style={style}
  {...listeners}
  {...attributes}
  onClick={(e) => e.stopPropagation()}  // DayCell.onClick 버블 방지
>
```
