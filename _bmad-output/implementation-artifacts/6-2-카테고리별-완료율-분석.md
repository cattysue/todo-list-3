# Story 6.2: 카테고리별 완료율 분석

Status: review

## Story

사용자(Catty)로서,
카테고리별 완료율을 비교하는 차트를 보는 것을 원한다,
어느 영역의 할일을 잘 처리하고 어느 영역에서 실행력이 떨어지는지 파악할 수 있도록.

## Acceptance Criteria

1. **카테고리 분석 섹션**: `/stats` 페이지의 기존 주간·월간 완료율 차트(Story 6.1) 아래에 "카테고리별 완료율" 섹션이 추가된다. 각 카테고리별 완료율(완료 수 / 전체 수 × 100)이 비교 차트로 표시되며, 완료율이 높은 순서로 정렬되어 한눈에 구분할 수 있다.

2. **카테고리별 집계 API**: `GET /stats/category` 호출 시 카테고리별 전체 할일 수(`total_count`), 완료 할일 수(`completed_count`), 완료율(`completion_rate`)이 반환된다. 카테고리 없는 할일(`category_id = NULL`)은 집계에서 제외된다. 완료율 내림차순으로 정렬하여 반환한다.

3. **빈 카테고리 처리**: 할일이 없는 카테고리(카테고리는 존재하나 할일 0개)는 응답에서 제외된다. 모든 카테고리에 할일이 없을 경우 차트 대신 "분석할 데이터가 없습니다" 문구가 표시된다.

4. **페이지 통합**: 주간·월간 완료율 차트(6.1)와 카테고리 분석 차트가 동일한 `/stats` 페이지 내 두 개의 구분된 `<section>` 영역으로 표시된다. 두 섹션 모두 각자 독립적인 로딩/에러 상태를 가진다.

    ```python
    def get_category_stats(user_id: str, supabase) -> dict:
        """
        카테고리별 완료율을 집계한다.
        category_id가 NULL인 할일은 제외한다.
        할일이 없는 카테고리는 결과에서 제외된다.
        완료율 내림차순으로 정렬하여 반환한다.
        """
        rows = (
            supabase.table("todos")
            .select("id, is_completed, category_id, categories(name)")
            .eq("user_id", user_id)
            .execute()
            .data
        ) or []

        category_map: dict[str, dict] = {}
        for row in rows:
            cat_id = row.get("category_id")
            if not cat_id:
                continue
            cats = row.get("categories")
            cat_name = cats.get("name") if isinstance(cats, dict) else cat_id
            if cat_id not in category_map:
                category_map[cat_id] = {
                    "category_id": cat_id,
                    "category_name": cat_name,
                    "total_count": 0,
                    "completed_count": 0,
                }
            category_map[cat_id]["total_count"] += 1
            if row.get("is_completed"):
                category_map[cat_id]["completed_count"] += 1

        result = []
        for data in category_map.values():
            total = data["total_count"]
            completed = data["completed_count"]
            raw_rate = completed / total * 100 if total > 0 else 0.0
            rate = round(min(100.0, raw_rate), 1)
            result.append({
                "category_id": data["category_id"],
                "category_name": data["category_name"],
                "total_count": total,
                "completed_count": completed,
                "completion_rate": rate,
            })

        result.sort(key=lambda x: x["completion_rate"], reverse=True)
        return {"data": result}
    ```

### `categories` JOIN 패턴

기존 `backend/services/todos.py`에서 검증된 패턴:
```python
.select("*, categories(name)")
```

`get_category_stats`에서도 동일하게 `categories(name)` JOIN을 사용한다. Supabase가 반환하는 `row["categories"]`는 `{"name": "업무"}` 딕셔너리 형태이다. `isinstance(cats, dict)` 체크 후 `.get("name")` 사용.

### 카테고리 없는 할일 처리

`category_id = NULL`인 할일은 Python 레벨에서 `if not cat_id: continue`로 제외한다. Supabase 쿼리 레벨 필터 불필요 — 전체 할일을 한 번에 가져와서 Python에서 분류하는 것이 더 간단하고 안전하다.

### 수평 바 차트 (layout="vertical") 패턴

카테고리 이름은 Y축(type="category"), 완료율은 X축(type="number", 0~100%)이다. Recharts `BarChart`에 `layout="vertical"` 속성을 주면 수평 바가 된다.

차트 높이는 카테고리 수에 비례: `Math.max(200, data.length * 52)`. 카테고리가 많아질수록 차트가 세로로 늘어난다.

백엔드에서 이미 `completion_rate` 내림차순으로 정렬되어 반환되므로, 프론트엔드에서 별도 정렬 불필요. 수평 바 차트에서는 위에 있는 것이 먼저 표시되므로 첫 번째 항목(완료율 높음)이 상단에 위치한다.
