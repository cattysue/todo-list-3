# Story 5.1: 캘린더 뷰 페이지 구현

Status: done

## Story

사용자(Catty)로서,
캘린더 탭에서 마감일 기준 월간/주간 달력으로 할일을 보는 것을 원한다,
마감이 몰린 날과 여유로운 날을 시각적으로 한눈에 파악할 수 있도록.

## Acceptance Criteria

1. **월간/주간 뷰 표시**: `/calendar` 페이지에서 월간 뷰와 주간 뷰 전환 탭이 표시되고, 마감일이 있는 할일들이 해당 날짜 셀에 표시된다.

2. **날짜 클릭 → 할일 목록 상세 패널**: 캘린더의 특정 날짜를 클릭하면 해당 날짜의 할일 목록이 상세 패널로 표시된다. 각 할일의 제목·우선순위·완료 여부가 표시된다.

3. **오버플로우 표시**: 달력 셀에 표시 가능한 최대 3개를 초과하면 "+N개 더" 텍스트가 표시된다.

4. **월간/주간 뷰 전환**: 탭 클릭 시 해당 뷰에 맞는 달력 레이아웃으로 즉시 전환된다.

- [x] Task 9: `frontend/src/lib/calendarUtils.ts` 신규 생성 — 날짜 계산 유틸리티 (AC: 1, 4)
  ```typescript
  export function formatDate(date: Date): string {
    const y = date.getFullYear();
    const m = String(date.getMonth() + 1).padStart(2, '0');
    const d = String(date.getDate()).padStart(2, '0');
    return `${y}-${m}-${d}`;
  }

  export function getMonthRange(date: Date): { start: string; end: string } {
    const start = new Date(date.getFullYear(), date.getMonth(), 1);
    const end = new Date(date.getFullYear(), date.getMonth() + 1, 0);
    return { start: formatDate(start), end: formatDate(end) };
  }

  export function getWeekRange(date: Date): { start: string; end: string } {
    const isoDay = date.getDay() === 0 ? 6 : date.getDay() - 1; // Mon=0, Sun=6
    const monday = new Date(date);
    monday.setDate(date.getDate() - isoDay);
    const sunday = new Date(monday);
    sunday.setDate(monday.getDate() + 6);
    return { start: formatDate(monday), end: formatDate(sunday) };
  }

  // Month grid: returns all days to display (Mon-Sun rows, padded with prev/next month days)
  export function getMonthGridDays(date: Date): Date[] {
    const year = date.getFullYear();
    const month = date.getMonth();
    const firstDay = new Date(year, month, 1);
    const lastDay = new Date(year, month + 1, 0);

    const startPad = firstDay.getDay() === 0 ? 6 : firstDay.getDay() - 1;
    const endPad = lastDay.getDay() === 0 ? 0 : 7 - lastDay.getDay();

    const gridStart = new Date(firstDay);
    gridStart.setDate(1 - startPad);
    const gridEnd = new Date(lastDay);
    gridEnd.setDate(lastDay.getDate() + endPad);

    const days: Date[] = [];
    const cur = new Date(gridStart);
    while (cur <= gridEnd) {
      days.push(new Date(cur));
      cur.setDate(cur.getDate() + 1);
    }
    return days;
  }

  export function getWeekDays(date: Date): Date[] {
    const isoDay = date.getDay() === 0 ? 6 : date.getDay() - 1;
    const monday = new Date(date);
    monday.setDate(date.getDate() - isoDay);
    return Array.from({ length: 7 }, (_, i) => {
      const d = new Date(monday);
      d.setDate(monday.getDate() + i);
      return d;
    });
  }

  export function isSameMonth(date: Date, reference: Date): boolean {
    return (
      date.getFullYear() === reference.getFullYear() &&
      date.getMonth() === reference.getMonth()
    );
  }

  export function isToday(date: Date): boolean {
    return formatDate(date) === formatDate(new Date());
  }

  export function navigateMonth(date: Date, direction: 1 | -1): Date {
    return new Date(date.getFullYear(), date.getMonth() + direction, 1);
  }

  export function navigateWeek(date: Date, direction: 1 | -1): Date {
    const d = new Date(date);
    d.setDate(d.getDate() + direction * 7);
    return d;
  }
  ```

  'use client';

  import { useMemo, useState } from 'react';
  import { useCalendar } from '@/hooks/useCalendar';
  import { MonthView } from '@/components/calendar/MonthView';
  import { WeekView } from '@/components/calendar/WeekView';
  import { DayDetailPanel } from '@/components/calendar/DayDetailPanel';
  import {
    getMonthRange,
    getWeekRange,
    navigateMonth,
    navigateWeek,
  } from '@/lib/calendarUtils';
  import type { CalendarView } from '@/types/calendar';
  import type { TodoCalendarItem } from '@/types/calendar';
  import CalendarLoading from './loading';

  export default function CalendarPage() {
    const [view, setView] = useState<CalendarView>('month');
    const [currentDate, setCurrentDate] = useState<Date>(new Date());
    const [selectedDate, setSelectedDate] = useState<string | null>(null);

    const range = useMemo(
      () => (view === 'month' ? getMonthRange(currentDate) : getWeekRange(currentDate)),
      [view, currentDate],
    );

    const { data: todos = [], isLoading, isError } = useCalendar(range.start, range.end);

    // Group todos by due_date (YYYY-MM-DD)
    const todosByDate = useMemo(() => {
      const map: Record<string, TodoCalendarItem[]> = {};
      for (const todo of todos) {
        const key = todo.due_date.slice(0, 10);
        if (!map[key]) map[key] = [];
        map[key].push(todo);
      }
      return map;
    }, [todos]);

    const selectedTodos = selectedDate ? (todosByDate[selectedDate] ?? []) : [];

    function handleNavigate(direction: 1 | -1) {
      setCurrentDate((prev) =>
        view === 'month' ? navigateMonth(prev, direction) : navigateWeek(prev, direction),
      );
      setSelectedDate(null);
    }

    const monthLabel = currentDate.toLocaleDateString('ko-KR', { year: 'numeric', month: 'long' });
    const weekStart = (() => {
      const r = getWeekRange(currentDate);
      return `${r.start} ~ ${r.end}`;
    })();

    if (isLoading) return <CalendarLoading />;

    return (
      <main className="max-w-5xl mx-auto p-4">
        {/* View toggle */}
        <div className="flex items-center justify-between mb-4">
          <div className="flex gap-2">
            <button
              onClick={() => { setView('month'); setSelectedDate(null); }}
              className={['px-4 py-1.5 rounded text-sm font-medium', view === 'month' ? 'bg-blue-600 text-white' : 'bg-gray-100 text-gray-700'].join(' ')}
            >
              월간
            </button>
            <button
              onClick={() => { setView('week'); setSelectedDate(null); }}
              className={['px-4 py-1.5 rounded text-sm font-medium', view === 'week' ? 'bg-blue-600 text-white' : 'bg-gray-100 text-gray-700'].join(' ')}
            >
              주간
            </button>
          </div>
          {/* Navigation */}
          <div className="flex items-center gap-3">
            <button onClick={() => handleNavigate(-1)} className="px-2 py-1 text-gray-600 hover:bg-gray-100 rounded">&lt;</button>
            <span className="text-sm font-semibold w-44 text-center">
              {view === 'month' ? monthLabel : weekStart}
            </span>
            <button onClick={() => handleNavigate(1)} className="px-2 py-1 text-gray-600 hover:bg-gray-100 rounded">&gt;</button>
          </div>
        </div>

        {isError && (
          <p role="alert" className="text-red-600 mb-4 text-sm">
            캘린더 데이터를 불러오는 중 오류가 발생했습니다.
          </p>
        )}

        {/* Calendar + Detail Panel */}
        <div className={['flex gap-4', selectedDate ? 'flex-row' : ''].join(' ')}>
          <div className={selectedDate ? 'flex-1' : 'w-full'}>
            {view === 'month' ? (
              <MonthView
                currentDate={currentDate}
                todosByDate={todosByDate}
                selectedDate={selectedDate}
                onSelectDate={setSelectedDate}
              />
            ) : (
              <WeekView
                currentDate={currentDate}
                todosByDate={todosByDate}
                selectedDate={selectedDate}
                onSelectDate={setSelectedDate}
              />
            )}
          </div>
          {selectedDate && (
            <div className="w-64 shrink-0">
              <DayDetailPanel
                dateStr={selectedDate}
                todos={selectedTodos}
                onClose={() => setSelectedDate(null)}
              />
            </div>
          )}
        </div>
      </main>
    );
  }

### 백엔드 서비스 설계

```python
# backend/services/calendar.py
from datetime import date, timezone, datetime
from typing import Optional

def _build_calendar_item(row: dict) -> dict:
    categories = row.get("categories") or {}
    category_name = categories.get("name") if isinstance(categories, dict) else None
    return {
        "id": row["id"],
        "title": row["title"],
        "due_date": row.get("due_date"),
        "priority": row.get("priority"),
        "is_completed": row.get("is_completed", False),
        "created_at": row.get("created_at"),
        "category_id": row.get("category_id"),
        "category_name": category_name,
    }

def get_calendar_todos(
    user_id: str,
    start: str,   # YYYY-MM-DD
    end: str,     # YYYY-MM-DD
    supabase,
) -> list[dict]:
    response = (
        supabase.table("todos")
        .select("*, categories(name)")
        .eq("user_id", user_id)
        .not_.is_("due_date", "null")
        .gte("due_date", start)
        .lte("due_date", end)
        .order("due_date", desc=False)
        .execute()
    )
    rows = response.data or []
    return [_build_calendar_item(row) for row in rows]
```

### 백엔드 라우터 설계

```python
# backend/routers/calendar.py
from datetime import datetime, timedelta, timezone
from typing import Optional

from fastapi import APIRouter, Depends

from schemas.calendar import TodoCalendarItem
from services.calendar import get_calendar_todos
from dependencies import get_current_user, get_supabase, require_user_id

router = APIRouter(prefix="/todos", tags=["calendar"])

@router.get("/calendar", response_model=list[TodoCalendarItem])
def get_calendar(
    start: Optional[str] = None,  # YYYY-MM-DD
    end: Optional[str] = None,    # YYYY-MM-DD
    current_user=Depends(get_current_user),
    supabase=Depends(get_supabase),
):
    user_id = require_user_id(current_user)
    today = datetime.now(timezone.utc).date()
    resolved_start = start or today.replace(day=1).isoformat()
    if end:
        resolved_end = end
    else:
        # 이번 달 말일
        next_month = today.replace(day=28) + timedelta(days=4)
        resolved_end = next_month.replace(day=1) - timedelta(days=1)
        resolved_end = resolved_end.isoformat()
    return get_calendar_todos(
        user_id=user_id,
        start=resolved_start,
        end=resolved_end,
        supabase=supabase,
    )
```

**⚠️ 주의**: `prefix="/todos"`로 설정 — `GET /todos/calendar` 경로가 된다. 하지만 `routers/todos.py`도 동일 prefix를 사용하므로 `main.py`에서 두 라우터를 모두 등록하면 FastAPI가 경로를 병합한다. 이것은 의도된 동작이며 `routers/dashboard.py`와 동일한 패턴이다.

### 주의: `/todos/calendar` vs `/todos/{todo_id}` 라우터 충돌

**중요**: `todos.py`의 `GET /todos/{todo_id}` 경로 파라미터가 `calendar`를 문자열로 받을 수 있다. FastAPI는 라우터 등록 순서에 따라 먼저 매칭되는 라우터가 처리한다.

**해결**: `main.py`에서 `calendar.router`를 `todos.router` **앞에** 등록하면 `/todos/calendar`가 정적 경로로 먼저 매칭된다.

```python
# main.py — 등록 순서 중요!
app.include_router(dashboard.router)
app.include_router(calendar.router)   # calendar 먼저!
app.include_router(todos.router)      # 그 다음 todos
app.include_router(categories.router)
app.include_router(templates.router)
```

### `calendarUtils.ts`의 날짜 계산 주의사항

- `new Date()` → 브라우저 로컬 타임존 기준. 화면 표시용(날짜 숫자, 이번 달 레이블)에만 사용.
- API 쿼리용 start/end → `formatDate(date)`로 생성 (YYYY-MM-DD 문자열).
- 서버 UTC 기준 데이터 vs. 브라우저 표시 사이의 타임존 차이가 발생할 수 있지만, 날짜 범위 필터이므로 하루 오차 수준이며 MVP에서 허용.

### `getMonthGridDays` 로직 설명

월간 그리드는 항상 월요일부터 시작 (ISO 기준):
- 1일이 수요일(isoDay=2)이면 앞에 월·화(2개) 패딩
- 말일이 금요일(isoDay=4)이면 뒤에 토·일(2개) 패딩

인접 월 날짜는 `isCurrentMonth=false`로 `DayCell`에 전달 → 회색 처리. 해당 날짜의 todos는 API 응답에 없으므로 빈 배열로 처리되어 표시되지 않음.

### 캘린더 상태 관리

```
page.tsx state:
  view: 'month' | 'week'        → 뷰 전환
  currentDate: Date             → 현재 월/주 기준 날짜
  selectedDate: string | null   → 클릭된 날짜 (YYYY-MM-DD)

  todosByDate: Record<string, TodoCalendarItem[]>  → todos 그루핑
  selectedTodos: TodoCalendarItem[]  → selectedDate의 todos
```

### `todosByDate` 그루핑

API 반환 `due_date`는 Pydantic이 `date` 객체로 직렬화 후 ISO 문자열(`YYYY-MM-DD`)로 응답. 프론트는 `.slice(0, 10)`으로 날짜 키를 추출:

```typescript
const key = todo.due_date.slice(0, 10); // "2026-06-15T00:00:00" → "2026-06-15"
```

`due_date`가 순수 `date`이면 이미 `"2026-06-15"` 형태이므로 `.slice(0, 10)` 항상 안전.
