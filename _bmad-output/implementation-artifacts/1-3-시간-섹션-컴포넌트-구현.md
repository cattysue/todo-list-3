# Story 1.3: 시간 섹션 컴포넌트 구현 (기한 초과·오늘·내일·이번 주)

Status: done

## Story

사용자(Catty)로서,
대시보드의 각 섹션이 올바른 할일을 적절한 시각적 스타일과 정렬로 표시하는 것을 원한다,
기한 초과·오늘·내일·이번 주에 해당하는 할일을 구분하여 즉시 파악할 수 있도록.

## Acceptance Criteria

1. **기한 초과 섹션 조건부 렌더링**: 기한 초과 할일이 1개 이상일 때만 "기한 초과" 섹션이 DOM에 렌더링된다. 0개이면 섹션 자체가 보이지 않는다.

2. **기한 초과 섹션 시각적 강조**: "기한 초과" 섹션 헤더 또는 항목에 빨간색 시각적 강조가 적용된다. 각 항목에 카테고리 이름(`category_name`)이 표시된다.

3. **기한 초과 섹션 위치**: "기한 초과" 섹션이 다른 모든 섹션보다 최상단에 표시된다.

4. **오늘 마감 섹션 항상 렌더링**: 오늘 마감 할일이 0개일 때 목록 대신 "오늘 마감 없음" 빈 상태 메시지가 표시된다. 1개 이상일 때는 목록이 표시된다.

5. **우선순위 순서**: 오늘 마감 섹션의 항목 표시 순서는 API 응답 순서 그대로 사용한다 (백엔드가 이미 우선순위 내림차순 + created_at 오름차순으로 정렬함).

6. **내일·이번 주 섹션 독립 렌더링**: "내일 마감"과 "이번 주 마감" 섹션이 각각 독립적으로 렌더링된다. "이번 주 마감"에 내일 항목이 중복 표시되지 않는다 (백엔드가 보장).

7. **섹션 렌더링 순서**: 기한 초과 → 오늘 마감 → 내일 마감 → 이번 주 마감 순으로 표시된다.

### 핵심 제약 사항 (절대 위반 금지)

- **프론트엔드에서 데이터 재정렬 금지**: 백엔드 API가 이미 정렬해서 응답함 (overdue: due_date asc, today: priority desc + created_at asc). `[...items].sort(...)` 호출 금지.
- **날짜 기준 재분류 금지**: `overdue`/`today`/`tomorrow`/`this_week` 결정은 백엔드 몫. 프론트에서 `item.due_date`로 재분류 금지.
- **`queryKeys.ts` 외부 쿼리 키 문자열 리터럴 사용 금지**: 이 스토리에서 새로운 쿼리를 추가하는 경우에도 동일 규칙 적용.
- **`data-testid` 속성 유지**: `page.tsx`의 `data-testid={`section-${key}`}` 테스트에서 의존. 섹션 컴포넌트 교체 후에도 반드시 유지.

### 컴포넌트 구현 패턴

**OverdueSection** (조건부 렌더링 + 빨간색 강조):
```tsx
// frontend/src/components/dashboard/OverdueSection.tsx
import type { TodoDashboardItem } from '@/types/dashboard';

export function OverdueSection({ items }: { items: TodoDashboardItem[] }) {
  if (items.length === 0) return null;  // 섹션 자체 숨김
  return (
    <>
      <h2 className="text-lg font-semibold text-red-600 mb-2">기한 초과</h2>
      <ul>
        {items.map((item) => (
          <li key={item.id} className="py-1 border-b border-red-100">
            <span>{item.title}</span>
            {item.category_name && (
              <span className="text-sm text-gray-500 ml-2">{item.category_name}</span>
            )}
          </li>
        ))}
      </ul>
    </>
  );
}
```

**TodaySection** (항상 렌더링, 빈 상태):
```tsx
// frontend/src/components/dashboard/TodaySection.tsx
export function TodaySection({ items }: { items: TodoDashboardItem[] }) {
  return (
    <>
      <h2 className="text-lg font-semibold mb-2">오늘 마감</h2>
      {items.length === 0 ? (
        <p className="text-gray-400 text-sm">오늘 마감 없음</p>
      ) : (
        <ul>
          {items.map((item) => (
            <li key={item.id} className="py-1 border-b border-gray-100">
              {item.title}
            </li>
          ))}
        </ul>
      )}
    </>
  );
}
```

> )}

> AC 1 원문: "DOM에 렌더링되지 않는다" → `data-testid` wrapper까지 제거하는 방식 권장.
