### 생성된 아이디어 전체 목록

**[아이디어 #1]: 오늘의 할일 섹션 (Today's Focus)**
_Concept_: 앱을 열면 가장 상단에 "오늘 마감" 할일들만 모아서 보여주는 전용 섹션. 카테고리 관계없이 날짜 기준으로 자동 집계.
_Novelty_: 카테고리 중심이 아닌 시간 중심의 뷰 — 사용자가 지금 당장 뭘 해야 하는지 즉시 파악 가능.

**[아이디어 #2]: 시간대별 할일 뷰 (Timeline Dashboard)**
_Concept_: 대시보드를 "오늘 / 내일 / 이번 주" 섹션으로 나눠서 시간 흐름에 따라 할일을 자동 분류해서 보여줌.
_Novelty_: 카테고리가 아닌 시간 축으로 앱을 재편 — 사용자가 우선순위를 별도로 고민하지 않아도 자연스럽게 파악 가능.

**[아이디어 #3]: 기한 초과 알림 섹션 (Overdue Alert Zone)**
_Concept_: 대시보드 상단에 기한이 지난 미완료 할일을 빨간색으로 강조 표시. "오늘 / 내일 / 이번 주 / 기한 초과" 4단계 구조.
_Novelty_: 사용자가 놓친 할일을 능동적으로 드러내줌 — 묻히지 않고 반드시 인지하게 만드는 구조.

**[아이디어 #4]: 스마트 마감 알림 (Smart Due Date Notifications)**
_Concept_: 마감 하루 전, 당일 아침에 자동으로 브라우저 푸시 알림 또는 이메일 알림 발송. "내일 마감 3개, 오늘 마감 1개" 같은 요약형 알림.
_Novelty_: 사용자가 앱을 열지 않아도 앱이 먼저 사용자를 찾아오는 구조 — 수동적 앱에서 능동적 앱으로 전환.

**[아이디어 #5]: 알림 개인화 설정 (Notification Preferences)**
_Concept_: 사용자가 알림 시점(1일 전 / 3시간 전 / 당일 아침 9시 등)과 채널(이메일 / 브라우저 푸시)을 직접 설정 가능.
_Novelty_: 획일적 알림이 아닌 사용자 라이프스타일에 맞춘 알림 — 알림 피로도 없이 실질적으로 도움이 되는 타이밍.

**[아이디어 #6]: 생산성 통계 대시보드 (Productivity Stats)**
_Concept_: 주간/월간 완료율, 카테고리별 할일 분포, 평균 완료 소요 시간 등을 차트로 시각화. "이번 주 10개 중 7개 완료 (70%)" 같은 요약 제공.
_Novelty_: 단순한 할일 관리를 넘어 자신의 생산성 패턴을 발견하게 해주는 자기인식 도구로 진화.

**[아이디어 #7]: 카테고리별 완료율 분석**
_Concept_: "업무 카테고리는 완료율 80%, 개인 카테고리는 40%" 처럼 카테고리별로 어떤 영역을 잘 처리하고 못 처리하는지 비교.
_Novelty_: 어느 카테고리에서 실행력이 떨어지는지 시각적으로 인지 — 자기 개선의 출발점 제공.

**[아이디어 #8]: 반복 할일 (Recurring Todos)**
_Concept_: 할일 생성 시 반복 주기 설정 가능 — 매일 / 매주 특정 요일 / 매월 특정 날짜. 완료 체크하면 다음 주기에 자동으로 새 할일이 생성됨.
_Novelty_: 루틴성 할일을 매번 입력할 필요 없음 — 한 번 설정으로 자동화.

**[아이디어 #9]: 반복 할일 유연한 제어**
_Concept_: 반복 할일에 "이번만 건너뛰기 / 일시 중지 / 종료" 옵션 제공. 건너뛴 기록도 통계에서 확인 가능.
_Novelty_: 엄격한 반복이 아닌 삶의 유동성을 반영한 유연한 루틴 관리 — 부담 없이 반복 설정 가능.

**[아이디어 #10]: 할일 묶음 템플릿 (Todo Bundle Templates)**
_Concept_: 자주 사용하는 할일 묶음을 템플릿으로 저장. "여행 준비", "주간 루틴", "프로젝트 시작" 등을 원클릭으로 불러와 한 번에 여러 할일 생성.
_Novelty_: 반복적인 프로젝트나 루틴을 매번 처음부터 입력하는 수고 없이 즉시 시작 가능 — 할일 앱이 워크플로우 도구로 진화.

**[아이디어 #11]: 템플릿 공유 기능**
_Concept_: 내가 만든 템플릿을 링크로 공유하거나, 다른 사용자의 템플릿을 가져와 내 앱에 적용. "스터디 플래너", "독서 기록" 같은 커뮤니티 템플릿.
_Novelty_: 개인 생산성 도구에 커뮤니티 레이어를 추가 — 혼자 만들 필요 없이 검증된 워크플로우를 바로 활용.

**[아이디어 #12]: 할일 검색 (Todo Search)**
_Concept_: 제목 키워드로 전체 할일을 실시간 검색. 카테고리 필터와 조합해서 "업무 카테고리에서 '보고서' 검색" 같은 세밀한 탐색 가능.
_Novelty_: 카테고리가 많아질수록 탐색 시간이 줄어드는 구조 — 앱 규모가 커져도 빠른 접근성 유지.

**[아이디어 #13]: 고급 필터링 (Advanced Filtering)**
_Concept_: 검색에 필터 조합 추가 — 우선순위별 / 마감일 범위별 / 완료 여부별 / 카테고리별로 복합 필터링. "이번 주 마감 + 높은 우선순위 + 미완료" 같은 조합.
_Novelty_: 단순 키워드 검색을 넘어 상황에 맞는 할일 목록을 즉시 추출 — 정렬과 탐색이 동시에 해결.

**[아이디어 #14]: 캘린더 뷰 (Calendar View)**
_Concept_: 마감일 기준으로 할일을 달력에 표시. 월간/주간 캘린더에서 날짜별 할일 개수와 제목을 한눈에 파악. 날짜 클릭 시 해당 날의 할일 목록 표시.
_Novelty_: 리스트 중심 앱에 시간 축 기반 뷰를 추가 — 마감이 몰린 날과 여유로운 날을 시각적으로 즉시 파악 가능.

**[아이디어 #15]: 캘린더 드래그 마감일 변경**
_Concept_: 캘린더 뷰에서 할일을 다른 날짜로 드래그하면 마감일 자동 변경. 클릭해서 수정하는 것보다 훨씬 빠르고 직관적.
_Novelty_: 마감일 재조정이 게임처럼 자연스러운 경험 — 일정 충돌을 시각적으로 파악하며 즉시 조정 가능.
