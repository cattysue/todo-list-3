# Implementation Readiness Assessment Report

**Date:** 2026-06-01
**Project:** todo-list-3

## PRD Analysis

### Functional Requirements

FR-1: 사용자는 로그인 후 `/dashboard`를 기본 진입점으로 볼 수 있다. 마감일이 있는 미완료 할일을 시간 섹션으로 자동 분류하여 표시한다.
FR-2: 마감일 < today이고 미완료인 할일을 "기한 초과" 섹션에 빨간색 강조와 함께 대시보드 최상단에 표시한다.
FR-3: 마감일 = today인 미완료 할일을 "오늘 마감" 섹션에 우선순위 내림차순으로 표시한다.
FR-4: 내일 마감 할일과 이번 주 마감 할일을 별도 섹션으로 표시한다. 내일 항목이 먼저, 이번 주에 내일 항목 중복 없음.
FR-5: 사용자는 대시보드 각 항목에서 완료 체크를 할 수 있다. 즉시 사라지고 카테고리 뷰에도 동기 반영.
FR-6: 마감 하루 전 + 당일 아침 이메일 발송. "내일 마감 N개: [목록]" 형식. 완료 할일 제외. 0개면 미발송.
FR-7: 알림 시점(마감 N일/시간 전)과 채널(이메일/브라우저 푸시)을 설정 페이지에서 변경할 수 있다. 알림 완전 비활성화 옵션 제공.
FR-8: 브라우저 푸시 알림 — Phase 2 후반 NON-GOAL. 이메일 알림 안정화 이후 추가.
FR-9: 검색창 키워드 입력 시 전체 할일 제목 실시간 검색. 입력 후 300ms 이내 결과 갱신(debounce). 검색어 없을 때 전체 목록.
FR-10: 우선순위 / 마감일 범위 / 완료 여부 / 카테고리 필터 개별·조합 적용. 키워드 검색과 AND 조건. 필터 태그 개별 해제.
FR-11: 할일 생성·수정 시 반복 주기(매일/매주/매월) 설정. 완료 시 다음 주기 마감일로 새 인스턴스 자동 생성.
FR-12: 반복 할일에 "이번만 건너뛰기 / 일시 중지 / 반복 종료" 옵션 적용.
FR-13: 여러 할일을 묶은 이름 있는 템플릿 저장 및 불러오기. 불러오기 시 포함 할일 즉시 생성.
FR-14: 캘린더 탭에서 마감일 기준 월간/주간 뷰로 할일 표시. 날짜 클릭 시 해당 날 할일 목록 표시.
FR-15: 캘린더 뷰에서 할일 드래그 → 마감일 자동 변경. 즉시 대시보드·카테고리 뷰 반영.
FR-16: 통계 페이지에서 주간/월간 완료 개수와 완료율을 차트로 표시.
FR-17: 카테고리별 완료율을 비교하여 실행력 분석.
