# 프로덕트 브리프: todo-list-3 기능 확장

## 한 줄 요약

카테고리 중심에서 **시간 중심**으로 전환하여, 사용자가 "지금 뭘 해야 하는가"를 즉시 파악할 수 있는 할일 관리 앱으로 진화시킨다. 최종 목표는 생산성 관리 전체를 한 곳에서 해결하는 개인 워크플로우 허브다.

---

## 현재 상태

todo-list-3는 Next.js + FastAPI + Supabase + Railway 스택으로 구축된 카테고리 기반 할일 관리 웹앱이다. 현재 구현된 기능은 다음과 같다:

- 회원가입/로그인(인증)
- 카테고리 관리(생성·수정·삭제)
- 할일 CRUD(마감일, 우선순위 포함)

---

## 문제

핵심 데이터(마감일, 우선순위)는 이미 존재한다. 문제는 이 데이터를 제대로 보여주지 못하고 있다는 것이다.

현재 앱은 할일을 **카테고리별 리스트**로만 보여준다. 이 구조에서는:

- 오늘 마감인 할일이 어느 카테고리에 있는지 일일이 확인해야 한다.
- 기한이 지난 할일을 목록에서 찾아내기 어렵다.
- 사용자가 앱을 열어야만 무엇을 해야 하는지 알 수 있다.
- 할일이 쌓일수록 탐색이 불편해진다.

기능이 부족한 것이 아니라, **있는 데이터를 제대로 보여주지 못하는 것**이 핵심 문제다.

---

## 개발 로드맵

### Phase 1 — 시간 중심 대시보드 `[최우선]`

**목표:** 앱을 열었을 때 "지금 뭘 해야 하는가"가 즉시 보인다.

| 기능 | 설명 |
|------|------|
| 기한 초과 섹션 | 마감이 지난 미완료 할일을 상단에 빨간색으로 강조 |
| 오늘 마감 섹션 | 오늘 마감 할일만 자동 집계 |
| 내일 / 이번 주 섹션 | 시간 흐름에 따른 자동 분류 |

**구현 포인트:** FastAPI에서 마감일 기준 필터링 API 추가 → Next.js 대시보드 페이지 구성

---

### Phase 2 — 알림 + 탐색 `[2순위]`

**목표:** 앱 밖에서도 마감을 인지하고, 앱 안에서 빠르게 탐색한다.

| 기능 | 설명 |
|------|------|
| 스마트 마감 알림 | 마감 하루 전·당일 이메일 알림(시점·채널 사용자 설정 포함), 이후 브라우저 푸시 추가 |
| 할일 검색 | 키워드 실시간 검색 + 카테고리 필터 조합 |
| 고급 필터링 | 우선순위 / 마감일 범위 / 완료 여부 복합 필터 |

알림 기능은 이메일을 먼저 구현하고, 이후 브라우저 푸시를 추가하는 순서로 개발한다.

---

### Phase 3 — 할일 자동화 `[3순위]`

**목표:** 반복 입력 수고를 없애 루틴을 자동화한다.

| 기능 | 설명 |
|------|------|
| 반복 할일 | 매일 / 매주 / 매월 주기로 할일 자동 생성 |
| 반복 유연 제어 | 이번만 건너뛰기 / 일시 중지 / 종료 |
| 할일 묶음 템플릿 | 자주 쓰는 할일 묶음을 원클릭으로 불러오기 |

---

### Phase 4 — 고도화 `[장기]`

**목표:** 앱이 커진 후 시각적 탐색과 자기 분석을 지원한다.

| 기능 | 설명 |
|------|------|
| 캘린더 뷰 | 마감일 기준 월간/주간 달력 뷰 |
| 캘린더 드래그 마감일 변경 | 드래그로 직관적인 일정 재조정 |
| 생산성 통계 대시보드 | 주간/월간 완료율 차트 |
| 카테고리별 완료율 분석 | 어느 영역이 약한지 시각화 |

---

## 성공 기준

| 단계 | 기준 |
|------|------|
| Phase 1 완료 | 앱을 열었을 때 오늘 할 일이 3초 안에 파악됨 |
| Phase 2 완료 | 마감 전날 알림을 받고 앱을 열게 됨 |
| Phase 3 완료 | 매일 반복 입력이 필요 없어짐 |
| 전체 | 앱을 개인 생산성 도구로 실제로 매일 사용하게 됨 |
